# Projeto Steam

## 📝 Descrição do Projeto

O **Projeto Steam** é uma iniciativa desenvolvida por Ayrton Surica e Carlos Alberto para a disciplina de Desenvolvimento Web na Universidade Federal Fluminense (UFF). Este projeto consiste em um clone estático da plataforma Steam, com foco em replicar a interface e algumas de suas funcionalidades básicas. O objetivo principal foi aplicar e consolidar conhecimentos em desenvolvimento web front-end, criando uma experiência de usuário familiar e intuitiva, servindo como a base inicial para um projeto futuro mais abrangente com interações dinâmicas.

## 🎯 Objetivo

O principal objetivo deste projeto foi demonstrar a aplicação de conceitos de desenvolvimento web, resultando em uma interface funcional e visualmente similar à plataforma Steam original. O público-alvo principal para a avaliação deste projeto é o professor da disciplina.

## ✨ Funcionalidades Destacadas

  * **Página Inicial (Home - `index.html`):**
      * Exibição de jogos em destaque e recomendados com um carrossel interativo e efeitos visuais ao passar o mouse.
      * Navegação por categorias de jogos com transições visuais.
      * Barra de navegação superior e lateral (dropdown) com links para diversas seções da loja e comunidade.
      * Funcionalidade de login com validação de campos e uma barra de progresso simulada.
  * **Páginas de Detalhes de Jogos:**
      * Páginas dedicadas a jogos como "Marvel Rivals", "The Elder Scrolls V: Skyrim Special Edition" e "Hollow Knight", apresentando descrições, análises, datas de lançamento, desenvolvedores, distribuidoras, marcadores populares, requisitos de sistema e idiomas.
      * Galeria de imagens interativa (carrossel) para visualização do jogo.
      * Botão "Adicionar ao Carrinho" com simulação de compra e notificação Toast.
  * **Página "Sobre" (About):**
      * Informações sobre a plataforma Steam, incluindo estatísticas simuladas de jogadores online.
      * Vídeo de fundo dinâmico que pausa ao sair da área de visualização.
      * Seções informativas sobre a comunidade, hardware Steam e Steamworks, com imagens e descrições.
      * Efeito de parallax nas imagens.
  * **Páginas "Em Construção":**
      * Páginas `in_construction.html` foram criadas como placeholders para seções que não foram implementadas, visando simplificar o escopo do projeto devido a restrições de tempo. Elas indicam que o conteúdo estará disponível futuramente.
  * **Responsividade:**
      * O layout é adaptável e otimizado para uma visualização consistente em diferentes tamanhos de tela, incluindo desktops, tablets e dispositivos móveis.

## 💻 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias front-end:

  * **HTML5**
  * **CSS3**
  * **JavaScript**
  * **Bootstrap 5.3.3**
  * **jQuery 3.7.1**

Não há interações com APIs externas, pois este é um projeto estático, a ser expandido em fases futuras.

### Rodando Localmente (Opcional)

Para rodar o projeto em sua máquina local, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/ayrtonsur/ProjetoDevWeb.git
    ```
2.  **Navegue até o diretório do projeto:**
    ```bash
    cd ProjetoDevWeb/ProjetoDevWeb-deploy
    ```
3.  **Abra o arquivo `index.html`:**
    Basta abrir o arquivo `index.html` em seu navegador de preferência para visualizar o projeto.
